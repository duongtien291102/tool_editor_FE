# ROADMAP.md

## Phase 1: Foundation & Scaffold (Tháng 1)

- Set up repository (Vite/Next.js, TypeScript, ESLint, Prettier, Husky).
- Thiết lập kiến trúc thư mục.
- Cấu hình Design System, Theme (Dark Mode), Tailwind CSS.
- Xây dựng hệ thống UI Components cơ bản (Button, Input, Dropdown, Modal).
- Xây dựng Layout Engine cơ bản (Resizable & Dockable Panels).

## Phase 2: Core Editor Framework (Tháng 2)

- Triển khai Global State Management (Zustand).
- Xây dựng Timeline Component cơ bản (Tracks, Playhead, Grid).
- Xây dựng Asset Manager (Upload, Drag & Drop).
- Kết nối Preview Player với Timeline (Realtime syncing).
- Implement hệ thống Keyboard Shortcuts cơ bản (Space to play, Delete, Cut, Copy, Paste).

## Phase 3: AI Integration & Data Flow (Tháng 3)

- Giao diện nhập Script/Prompt.
- Tích hợp luồng gọi API AI (Text-to-Speech, Text-to-Image, Text-to-Video).
- Tự động hóa việc sắp xếp assets sinh ra từ AI xuống Timeline.
- Xử lý Loading states, Skeleton UI khi chờ AI sinh dữ liệu.

## Phase 4: Advanced Editing & Polish (Tháng 4)

- Undo/Redo System toàn cục.
- Context Menu (Chuột phải vào clip, asset).
- Properties Panel nâng cao (Chỉnh sửa Text, Transform, Opacity).
- Keyframes & Animations.
- Tối ưu hóa hiệu năng (Rendering 60fps, xử lý hàng trăm clip trên timeline).

## Phase 5: Export & Collaboration (Tháng 5)

- Server-side / Client-side rendering queue.
- Quản lý Project Cloud.
- Template system (Lưu project thành mẫu).
